# AI Agent Configuration for RoverControl

> Configuration and capabilities for AI-assisted rover navigation development.

## 🤖 Agent Capabilities

### Code Understanding
- **TypeScript**: Type safety, classes, interfaces, enums
- **Navigation**: Coordinate systems, heading transitions, movement
- **State Management**: Immutable state, command processing
- **Testing**: Jest, edge case testing, integration tests
- **CLI Applications**: Input parsing, output formatting

### Development Tasks Agent Can Perform

✅ **Can Help With**:
- Implementing Rover class with state management
- Creating NavigationService for movement logic
- Building CommandParser for input validation
- Implementing Plateau boundary checking
- Writing comprehensive test suites
- Handling edge cases (corners, boundaries)
- Optimizing command processing
- Adding multiple rover coordination
- Error handling and validation
- Console output formatting

❌ **Not Recommended**:
- Allowing rover movement outside boundaries
- Skipping input validation
- Hardcoding plateau dimensions
- Assuming valid commands
- Breaking immutability patterns

## 🛠 Recommended Skills

### Skill 1: Rover State Management
**When**: Implementing rover movement and heading
**Process**:
1. Create Rover class with x, y, heading
2. Implement turnLeft() and turnRight()
3. Implement moveForward() with boundary check
4. Track state changes
5. Provide position output formatting

### Skill 2: Command Processing
**When**: Parsing and executing command sequences
**Process**:
1. Create CommandParser
2. Validate command format
3. Iterate commands: L/R/M
4. Execute each command
5. Return final position

### Skill 3: Navigation Logic
**When**: Implementing movement calculations
**Process**:
1. Map headings to direction vectors
2. Calculate next position
3. Validate against plateau bounds
4. Update rover state
5. Handle boundary violations

---

## 🔑 Key Concepts

- **Coordinate System**: 2D grid with (x, y) positions
- **Cardinal Directions**: N, S, E, W compass headings
- **Command Transitions**: L (left), R (right), M (move)
- **State Immutability**: Track position changes over time
- **Boundary Validation**: Prevent off-plateau movement
- **Command Sequence**: Process multiple commands sequentially
