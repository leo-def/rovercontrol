# Development Instructions for AI Agents - RoverControl

> Guidelines for AI-assisted development of the Mars rover navigation system.

## 🎯 Project Overview

- **Purpose**: Navigate rovers on Mars plateau with command sequences
- **Type**: Command-line utility (Node.js)
- **Tech Stack**: TypeScript, Node.js 16+, Jest for testing
- **Build**: TypeScript compiler (tsc)

---

## 🏗 Architecture Pattern

**Rover Control System**:
- **CLI Parser**: Read and validate input commands
- **Rover Model**: Track position and heading
- **Navigation Service**: Process movement commands
- **Plateau Bounds**: Validate movement boundaries

### Core Components
```
Rover           - Position and heading state
Plateau         - Navigation grid boundaries
CommandParser   - Parse input format
NavigationService - Execute L/R/M commands
RoverController - Coordinate rovers
```

---

## 📂 File Naming & Conventions

**Classes**: PascalCase
- `Rover.ts`, `Plateau.ts`, `CommandParser.ts`, `NavigationService.ts`

**Methods**: camelCase
- `moveForward()`, `turnLeft()`, `turnRight()`, `processCommands()`

**Interfaces**: PascalCase with leading `I` (TypeScript convention)
- `IPosition`, `IRover`

**Constants**: UPPER_SNAKE_CASE
- `MAX_COORDINATE`, `VALID_HEADINGS`, `VALID_COMMANDS`

**Variables**: descriptive camelCase
- `currentHeading`, `nextPosition`, `commandSequence`

---

## ✅ DO's

1. **DO** validate plateau boundaries before movement
2. **DO** handle invalid commands gracefully
3. **DO** test edge cases (boundaries, direction wrapping)
4. **DO** use immutable state patterns
5. **DO** implement comprehensive input validation

---

## ❌ DON'Ts

1. **DON'T** allow rover movement outside plateau
2. **DON'T** skip input format validation
3. **DON'T** hardcode plateau dimensions
4. **DON'T** assume valid command sequences
5. **DON'T** confuse compass directions

---

## 📋 Common Workflows

**Setting up rover**:
```typescript
// Define plateau bounds
const plateau = new Plateau(5, 5);

// Create rover at position with heading
const rover = new Rover(1, 2, 'N', plateau);

// Process command sequence
rover.processCommands(['L', 'M', 'L', 'M', 'L', 'M']);

// Get final position
console.log(rover.getPosition()); // "1 3 N"
```

**Processing commands from input**:
1. Parse input file/stdin
2. Extract plateau dimensions
3. For each rover:
   - Parse position and heading
   - Parse command string
   - Execute commands
   - Output final position

**Testing edge cases**:
- Rover at corner (0,0) moving west (should fail)
- Rover spinning in place (R, L, R, L)
- Multiple rovers on same plateau
- Large command sequences
- Invalid commands in sequence

**Running console version**:
```bash
npm run build              # Compile TypeScript
npm run start:console      # Run console application
npm test                   # Run test suite
```
